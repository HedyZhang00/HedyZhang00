我不懂代码，也不是程序员。
我擅长的是，把一个人的专业经验、思考方式和内容方法，整理成可以反复使用、持续迭代的 Skills。
很多人其实不缺专业能力，只是不知道怎么找到内容定位，怎么把脑子里的经验讲清楚，又怎么通过持续输出，让更多人看见自己的价值。
所以，我正在借助 AI 和 coding agent，把自己的内容方法做成开源 Skills，帮助更多有专业积累的人：
• 找到适合自己的内容定位
• 把零散经验整理成清晰方法
• 持续输出有价值的内容
• 用内容放大专业影响力
代码不是我的专业，只是我把方法分享出去、连接更多人的新工具。
